# 识字 · 给老人的汉字学习 App

给一位 60–80 岁、不太认字的老人做的识字 App：**认读《通用规范汉字表》一级字表全部 3500 字**，
每天 20 个新字（约 175 天），配 1 节生活数学、1 条生活百科。两个客户端——
老人自己学的，和家属在自己手机上看她学得怎么样的。

完全不联网也能学。所有内容、字体、笔顺都打进 APK。

> 这个项目最初是为我奶奶做的。里面的每一个取舍都来自"她能不能真的用起来"，
> 所以文档里会直接写哪些做法被否掉了、哪些坑真的踩过。

## 先摸底，再开学

老人不是零基础——会接微信视频的人，早就认识一批字。所以首次打开是一套**摸底**，
不是考试：

- **识字**：按 3500 字表占比分层抽 **120 字**（20/12/19/69），二选一认读
- **数学**：6 题定起点，答到哪算哪，答不上就从那儿教
- 认出的字**直接从字序剔除**。实测认 60 字 → 175 天缩到 172 天；
  如果她其实认识 500 字，周期会明显缩短
- 全程可跳过；答错只说"没关系，明天还会再见到它"，不出现红叉

摸底顺带产出家属端第一条有用数据：**"她原来认识约 N 个字"**。

## 怎么安排每天

四件事，不锁时段，什么时候做都行，做一点存一点：

```
学新字 → 温习旧字 → 生活数学 → 生活百科
```

- **复习**用间隔重复：D+1 / D+3 / D+8 / D+21，跨两个时段答对才算掌握
- **自动降速**：连续 7 天正确率低于 70%，每天新字自动减半并顺延周期，界面写明"计划已调整"
- **每 7 天一个巩固日**：不学新字，只温习

**只教认读，不教书写。** 这是 20 字/天能成立的前提——写字要一笔一划，量提不上去。
目标是"看见能读、知道意思"，不是会默写。笔顺动画是让她**看懂字的结构**，不是临摹。

## 界面：「靛墨」

设计系统的事实源是 [DESIGN.md](DESIGN.md)，配色按题材推导（不是套模板）：

- **琉璃绀**（蓝染 / 青花瓷的深蓝）做唯一强调色 —— 刻意避开"科技蓝"和"暖奶油 + 陶土红"
- **松烟墨**做正文（带蓝底的冷近黑），中性象牙白做纸
- **田字格是功能结构不是装饰**：它教间架比例，所以线必须看得见（实测 3.2:1）
- 一屏只有**一个**主角、**一处**强调色
- 纸（06:00–18:00）/ 墨（夜间）自动切换，OLED 下字重降一档补偿光晕

这套方向是**改了三版**改出来的。前两版被否掉的原因都写进 DESIGN.md 了：
第一版是通用 Dashboard 套纸色；第二版「描红」方向对了但把题材变成了满屏装饰
——量化下来留白只有 9.5%、每屏 20 个盒子、25 处强调色。
"简洁"最后是靠**删东西**做到的，不是调字号。

## 自己构建

前置：Node ≥22、pnpm、JDK 17、Android SDK（platform 36 + build-tools）、Python 3 + `fonttools brotli edge-tts`。

```bash
pnpm install

# 1. 内容：字表 → 词组 → 科普 → 百科 → 笔顺 → 校验
pnpm content:all

# 2. 音频（166 MB，仓库里没有，必须本地生成）
python packages/content/scripts/build_audio.py

# 3. 核心测试 + 内容校验
pnpm --filter @shi/core test
node packages/content/scripts/verify-content.mjs

# 4. 老人端
cd apps/learner
pnpm exec vite build
pnpm exec cap sync android
node ../../scripts/android-fix.mjs learner      # 本机环境补丁，见脚本注释
cd android && ./gradlew assembleRelease
```

家属端同理（`apps/monitor`）。同步服务：`cd services/sync && pnpm start`。

### 签名（仓库里没有任何密钥）

```bash
keytool -genkeypair -v -alias shizi -keyalg RSA -keysize 2048 -validity 10000 \
        -keystore apps/learner/android/shizi-release.keystore
cp apps/learner/android/keystore.properties.example apps/learner/android/keystore.properties
# 填入你的 storeFile / storePassword / keyAlias / keyPassword
```

没有 `keystore.properties` 时构建**照样成功**，只是产出 `app-release-unsigned.apk`
——**未签名的 APK 安卓装不上**，要装机就必须自己签名。

## 内容可以自己换

百科和科普都是 CSV，改完跑一条命令就会校验（字数、答案分布、日次连续性、音频齐备），
不合格会列出问题行号并拒绝构建：

- [docs/生活百科替换说明.md](docs/生活百科替换说明.md) — 12 大类 215 条怎么写
- [docs/科普替换说明.md](docs/科普替换说明.md) — 旧 90 条的写法（现并入百科）

写内容的三条硬规矩：写给耳朵不是写给眼睛（会被朗读）、一条只讲一件事、
具体到"第几步点什么"。判断题答案会自动打散到 A/B 各半——
否则全选 A 就能蒙对，家属端的正确率就没有意义了。

## 一句提醒

这个 App 的全部设计假设是"一位具体的老人"。如果你打算给自家长辈用，
**先确认两件事**：她听普通话是否舒服（音频是标准普通话，没有方言音色），
以及她戴眼镜看这个字号是否真的吃力——这两条任何设计规范都替代不了。
