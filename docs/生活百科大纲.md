## 一、手机使用（扩为 55 条，第一大类）

**写法原则**：每条必须落到「第几步点什么」的真实操作路径，不写概念。
每条正文 60–90 字（朗读约 30 秒），照 TTS 管线规格，可全文朗读。

### A. 微信（28 条）—— 她已会「接」，教「往外打」和其余全部

**语音/电话（6）**
1. 往外打视频电话：聊天界面右下角「+」→「视频通话」→ 等对方接
2. 语音通话（不是视频）：同样「+」→「语音通话」；流量不够时用这个
3. 按住说话怎么用：聊天框按住麦克风不松手 → 说话 → 松开就发出去了
4. 语音转文字（她收到的语音听不清时）：长按那条语音 →「转文字」
5. 别人的语音没听清怎么办：长按 → 转文字，字看不清就再点一次
6. 挂了电话想再看一遍说什么：翻聊天记录往上滑

**发照片/看（6）**
7. 发一张照片给孙子：聊天「+」→「相册」→ 点一张 → 右下角发送（原画）
8. 拍一张直接发：聊天「+」→「拍摄」→ 按白色圆圈拍 → 发送
9. 孙子发来的照片怎么存到手机：点开大图 → 右下角「…」→ 保存
10. 一次发好几张：「相册」里可以多选（勾几张再发）
11. 看孙子的朋友圈：发现页 → 朋友圈 → 顶端是他的头像；点图片放大看
12. 自己发朋友圈：朋友圈右上角相机 → 拍或选图 → 写一句 → 发表

**找/看（8）**
13. 家人的聊天找不到了：顶端「搜索」→ 打字或语音说名字
14. 把家人聊天置顶：长按聊天 →「置顶」，永远排在最上面
15. 联系人加新朋友（孙媳妇）：右上角 + → 添加朋友
16. 微信字体调大：我 → 设置 → 通用 → 字体大小 → 拖到最大
17. 看谁的步数：点他头像 → 资料页；点赞是那颗小红心
18. 微信支付零钱在哪：我 → 服务 → 钱包
19. 语音消息不小心没发出去（松手太快）：按住别松，说完了再松
20. 视频通话时怎么转语音：画面卡的时候，挂断重拨选「语音」

**安全（8）**
21. 红包怎么收：点开红包 → 拆；钱进了零钱或银行卡
22. 红包怎么发（节日）：聊天「+」→ 红包 → 填金额 → 输密码
23. 陌生人的转账不要收：不认识的人发转账一律不点
24. 群里让转账的（业主群/家人群被盗号）：先电话核实本人再动
25. 「你的微信被封了」都是假的：微信不会用群消息通知你封号
26. 扫码送鸡蛋别扫：天下没有免费鸡蛋，扫码就把自己信息给出去了
27. 有人拉进陌生股票群：退群，全是骗子
28. 点了可疑链接怎么办：不动钱、不输密码，告诉孙子

### B. 支付宝（8）—— 与微信支付互补，老人常用替代品

29. 支付宝首页有什么：最常用的就「扫一扫」「收付款」「充话费」
30. 付款码给人看（超市收银）：首页「付钱」→ 出条码 → 给收银员扫
31. 扫别人（小摊付款）：「扫一扫」→ 对准摊主的码 → 输金额 → 付
32. 查余额：首页搜「余额」或「我的」→ 总资产
33. 充话费：首页「充值」→ 输手机号 → 金额 → 付（30/50 元档最常）
34. 交水电费：首页搜「生活缴费」→ 选水/电 → 输户号
35. 支付宝也是你孙子的微信，能转账：选「转账」→ 手机号 → 金额
36. 花呗/借呗不要开：那是借钱，不是你的钱；开了一律关掉

### C. 手机本身（12）—— 所有 App 的地基

37. 字体调大（全局）：设置 → 显示 → 字体大小 → 拖最大
38. 音量怎么调：右侧两个长键，上加大下减小；静音就调到底
39. 亮度（屋里/太阳下）：下滑控制中心拖亮条；太阳底下拉最亮
40. 充电的正确习惯：见 80% 就拔，别整夜充；发热就摘壳
41. 屏幕乱跳了怎么退出：底部横线往上一滑（或底部按键「三」键）
42. 手机卡了：关掉重开（长按侧键 → 重启）；一周关一次最好
43. 「存储空间不足」：相册删旧视频最占地方；让孙子远程清
44. 锁屏密码忘了：找孙子，别自己试，锁死了要刷机
45. 通知红点怎么消除：长按图标 →「标记已读」
46. 误触付费/游戏扣钱：设置里关掉「免密支付」（或让孙子关）
47. 手机丢了第一时间：找家人打电话挂失 SIM 卡，再冻结支付
48. 流量（蜂窝）开关：控制中心「蜂窝数据」；家里 WiFi 自动连

### D. 常用 App（7）—— 看病/出行/天气/相册

49. **挂号 App**（约号看病）：用「微信挂号」（搜医院公众号 → 预约挂号）最简单，App 挂号给孙子代办
50. 网约出租车：微信「滴滴出行」小程序，或打车电话约；不想学 App 就用电话
51. 天气：手机自带「天气」App；看「未来三天」比看今天有用
52. 相册：照片按时间自动排；「相册」→ 底部「时间」/「人物」切分类；翻到最早是年轻照片
53. 打电话（基础中的基础）：绿色电话图标 → 数字 → 绿键；通讯录找不到人：右上角搜索
54. 短信验证码（60秒倒计时）：收到一串数字，别转发给别人，孙子问也不给（真孙子不会问）
55. 备忘录/日历提醒（可选给她）：日历 App 加生日提醒，全家孙辈生日她记得最清

> **注**：数字键「60秒倒计时」为短信验证码的口语描述，不指真实界面元素。

### E. 35→55 的增量理由

原 30 条版本只覆盖「微信 12 + 手机 8 + 支付 5 + App 5」。用户点名「常用 App + 具体用法」后：
- 微信扩为 28（老人 80% 手机时间在此）：**往外打视频**、朋友圈、语音转文字、红包收发、找回聊天
- 支付宝单列 8 条（很多老人与微信双轨）
- 手机地基 12 条（存储/误触扣费/丢失挂失——都是「手机出事」的真实痛点）
- 常用 App 7 条（挂号/打车/天气/相册/电话/验证码）
