# 装机与部署

## 一、装这两个 App

| 文件 | 装在哪 | 大小 |
| --- | --- | --- |
| `dist-apk/shizi-learner-release.apk` | 老人的平板或手机 | 91.6 MB |
| `dist-apk/shizi-monitor-release.apk` | 你自己的手机 | 3.1 MB |

**系统要求**：Android 7.0（API 24）及以上。两个 App 包名不同，可以装在同一台手机里。

### 安装步骤

1. 把 APK 传到手机（微信文件传输助手 / QQ / U 盘 / 数据线都行）
2. 点开 APK，系统会提示"未知来源应用"——去设置里给"文件管理"或"浏览器"打开**允许安装未知应用**
3. 装完桌面会出现「识字」和「家人学习情况」

> 这两个包用的是自签名证书，安装时 Play 商店的保护扫描可能提示"未经检测"，
> 选**继续安装**即可。这是自己签的包，不进应用商店。

### 老人端首次使用

打开就是首页，不需要注册、不需要登录、不需要联网。

第一次点「接着学」会从「一 二 三 四 五 十 百 万 人 口 手」开始。

**右上角的「自动 / 纸 / 墨」**：默认跟随时间自动换（6:00–18:00 白底，18:00 后黑底）。
老人要是嫌暗或嫌亮，点一下就能固定。

## 二、让家属端能看到数据（可选）

老人端**不联网也能完整学习**。但你要在自己手机上看到"今天学了没有"，中间需要一台
**一直开着的机器**当同步服务器——家里的旧电脑、树莓派、或者一台小 VPS 都行。

### 1. 在那台机器上启动同步服务

需要 Node.js 20 以上。把项目拷过去，然后：

```bash
cd services/sync
PORT=8787 DB_PATH=./data/sync.db node src/server.ts
```

看到 `同步服务已启动 http://0.0.0.0:8787` 就成了。

想开机自启的话，Windows 用「任务计划程序」，Linux 用 `systemd` 或 `pm2`。

### 2. 找到这台机器的局域网地址

Windows：

```powershell
ipconfig | Select-String "IPv4"
```

通常是 `192.168.x.x`。假设是 `192.168.1.10`，那同步地址就是：

```
http://192.168.1.10:8787
```

> **注意**：手机和这台机器必须在同一个 WiFi 下。如果你想在外面也能看，
> 需要做内网穿透（frp / tailscale），或者把它放到有公网 IP 的服务器上。

### 3. 配对

**老人端**：目前配对码需要从服务端生成，命令如下（后续版本会做进 App 设置页）：

```bash
curl -X POST http://192.168.1.10:8787/api/pairing \
  -H "Content-Type: application/json" \
  -d '{"learnerId":"elder-01"}'
# 返回 {"code":"483920","learnerId":"elder-01"}
```

**家属端**：打开「家人学习情况」，填两样东西：
- 同步地址：`http://192.168.1.10:8787`
- 配对码：上面返回的 6 位数字

点「配对」。成功后会显示今天的完成情况。

### 4. 你能看到什么

**今天页**
- 今天学过了 / 还没开始
- 四项完成度：新字几个、复习几个、数学做没做、科普看没看
- 正确率、用时

**趋势页**
- 最近 7 天复习量柱状图
- 累计新字、连续天数

**设置页**
- 给老人留言（老人端首页会出现"家人留言"）
- 调整每天新字数（老人吃力就调低）
- 解除配对

### 5. 会自动提醒你什么

下面这几种情况，家属端会显示提示：

| 情况 | 提示 |
| --- | --- |
| 20:00 后还没开始 | 今天还没开始学习 |
| 连续 2 天没学 | 已经 N 天没学了，要不要打个电话 |
| 最近 7 天正确率 <60% | 可能有点吃力，建议调低每天的字数 |

**不会提醒的**：老人答错了多少题、具体哪个字没记住、一天点了几次屏幕。
这是刻意的——这些数据用来判断教学效果，不该变成对老人的监视。

## 三、重新打包（改了内容之后）

```bash
# 1. 改内容（可选）
#    科普：packages/content/content/science.csv
#    数学：packages/content/content/math.json

# 2. 重建数据
pnpm content:science
pnpm content:math

# 3. 补音频（只补缺的）
python packages/content/scripts/build_audio.py --only lessons

# 4. 重建 web 并同步到 Android 工程
cd apps/learner
pnpm build
pnpm exec cap copy

# 5. 关键：cap copy 之后要重跑一次环境修复（Capacitor 会把 Java 版本改回 21）
cd ../..
node scripts/android-fix.mjs learner

# 6. 出包
cd apps/learner/android
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

## 四、已知限制

| 限制 | 说明 |
| --- | --- |
| 签名证书 | 密码写在 `apps/*/android/app/build.gradle` 里。这是自家侧载，不是商店分发，不需要更严的密钥管理。**如果换机器重装，要先卸载旧版**（签名不同不能覆盖装） |
| 配对码 | 目前要从命令行生成，还没做进老人端设置页 |
| 推送通知 | 家属端的提醒只在打开 App 时显示，不是系统推送。中国安卓没有 GMS，系统推送本来就不可靠 |
| 同步服务 | 只做局域网自建，没有云端托管 |
| iOS | 没做。当前目标是 Android |
