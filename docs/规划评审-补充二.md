## A. 辅助学习的功能（6 缺口之外的新发现）

按价值排，★★★ 优先做。

### A1. 专属字包：家人名字 ★★★（情感价值最高）

**做什么**：家属端输入「家人姓名 + 奶奶自己的名字 + 小区/村名 + 常去医院名」，生成她的专属字包，插进学习序列最前面。

**为什么值**：1800 字是「全国人民的平均」，不是「她的」字库。孙子的名字、自己的名字、家门口的路——这些字在她生活里的出现频率碾压任何字频表。而且**老人会写会认自己的名字有尊严价值**（签名、领东西不用只按手印）。

**可行性**：✅ 笔顺数据 9574 字覆盖（家人姓名大概率在内，罕见姓氏可报警提示家属）；音频管线现成，补生成即可；只缺家属端的输入界面。

### A2. 家人真声教字 ★★★（把机器音换成你的声音）

**做什么**：家属端对某几个字/某几句话**录自己的声音**，上传后老人端优先播放家人录音，TTS 做兜底。比如「小明教你念：重——重要的重」。

**为什么值**：孙子的声音和微软合成音，对奶奶是两种完全不同的东西。学习动机上没有任何 TTS 能替代。尤其配合 A1（教她认家人的名字）和留言阅读。

**可行性**：✅ 老人端播放是现成的（音频 URL 体系在）；家属端 MediaRecorder 录音 + 上传到同步服务，中等开发量。**需要家属真的愿意录**——这件事本身是「隔代陪伴」的替代形式，哪怕只录 50 个字。

### A3. 纸质字卡导出 ★★★（离屏陪练）

**做什么**：家属端把「常错字 TOP20」或指定字集导出成**可打印的 A4 PDF 字卡**（大字 + 拼音 + 词 + 音频二维码可选）。

**为什么值**：老人不是一天 8 小时在设备前，纸质字卡是传统识字教学的利器；老花眼对纸面大字最友好；还能变成「孙子来了一起重认」的线下道具——**当面陪练一次的效果超过 App 三天**。与弱点清单（缺口6）天然配套。

**可行性**：✅ 本机有 make-pdf/office 管线可复用，家属端加导出按钮即可。

### A4. 每日提醒（本地通知）★★☆（弃用的主防线）

**做什么**：每日固定时间（如早 9:00）本地通知「今天的新字准备好了」，点击直达首页。家属端可远程改提醒时间。

**为什么值**：老人「忘了打开 App」是弃用的第一原因。之前调研过：国产安卓无 GMS、Web Push 不可靠——**Capacitor 本地通知是当时就定的方案，还没落地**。

**可行性**：✅ `@capacitor/local-notifications 8.3.1` 已存在，装包即可。风险：国产 ROM（MIUI/EMUI）默认限制自启动与通知，需要装机时手动授权一次，写进部署文档。

### A5. 磨耳朵模式（把丢掉的「听一听」做实）★★☆

**做什么**：恢复「听一听」入口：顺序播放「今天的字 → 词 → 例句」音频队列，可锁屏连播；老人择菜、走路时听。

**为什么值**：听觉通道不占视力（老花友好）；重复暴露对记忆巩固有实证支持；不产生操作负担（她什么都不用点，放着就行）。

**可行性**：✅ 全部音频已在包内，只是顺序播放队列 + 播放器界面，开发量小。

### A6. 设置页：字号三档 + 语速三档 ★★

**做什么**：老人端加设置页（目前没有）：正文字号 24/28/32 三档、音频语速 0.8/0.85/0.92 三档、主题（自动/纸/墨，目前散在首页角落）、提醒时间。

**为什么值**：真机首测视力后她需要哪档，由她自己或你调。**DESIGN.md 里写了「支持更大字三档」，代码里根本没实现**——文档与实现不一致，要么实现要么删承诺。

**可行性**：✅ 纯前端，半天工作量。字号档位 = CSS 令牌切换；语速 = playbackRate 参数化（audio.ts 已集中管理，改一处）。

### A7. 写自己名字（描红最小集）★★

**做什么**：不教 1800 字全写（那是 20 字/天节奏不可能承受的），只做**「写自己的名字 + 数字」**的描红模块：hanzi-writer 的 quiz 模式（笔画描红、错笔提示、笔顺演示都是现成 API）。

**为什么值**：会写自己名字的尊严价值极高；数字签名场景真实（存单、快递）。这是上一轮评审「不建议写字」的**修正**——不矛盾：不写全量，只写名字+数字的最小集。

**可行性**：✅ 数据已在（hanzi-writer-data），只需装 `hanzi-writer@3.7.3` 库（npm 已确认存在），API 自带 quiz/描红。与 A1（专属字包含名字）联动。

### A8. 奶奶语音回信 ★☆（温暖但非必需）

**做什么**：老人端一个长按大按钮「给孙子说句话」，录音上传，家属端播放。

**为什么值**：奶奶说一句「今天学了 20 个字」的语音，对你的意义远大于一条日报。让「学」变成「能跟孙子说话」，动机闭环。

**可行性**：✅ MediaRecorder + 同步服务，中等。放在留言阅读（缺口2）之后做，同一套通道。

### 不做，且理由要写明

| 功能 | 为什么不做 |
| --- | --- |
| 跟读 ASR 评分（她念、机器判对错） | **方言口音会被普通话 ASR 大量误判**，老人被机器反复判「错」是挫败感放大器。可以做「跟读后听标准音」的对照模式（不评分），但自动判分不做 |
| 音量键翻页 | 与系统音量行为冲突，误触风险大于收益 |
| 横屏 | 老人端以竖屏手机/平板为主，低优先 |
| 手写输入法 | 语音输入已存在，手部精细动作对老人是负担 |

## B. 内容延伸拓展

### B1. 「读一读」场景库（若做缺口1，场景就这八个）★★★

全部只用已学字组句，按生活半径出题：

| 场景 | 示例内容 | 对应能力 |
| --- | --- | --- |
| **药盒** | 一日三次，一次一片 / 饭后服用 | 用药安全落地 |
| **微信** | 「妈，今晚视频」 / 孙子发的语音转文字 | 与家人沟通（最高动机） |
| **公交站牌** | 2 路开往火车站 / 本站：人民公园 | 出行 |
| **超市价签/小票** | 鸡蛋 六元一斤 / 合计 23.50 | 与数学「人民币」打通 |
| **医院** | 内科在三楼 / 挂号费 10 元 | 与数学「读数」打通 |
| **短信/通知** | 【快递】您的包裹已到菜鸟驿站 / 验证码 483920 | 与防诈骗打通（真短信 vs 诈骗短信对照） |
| **水电账单** | 本月用电 86 度 / 应缴 43.00 元 | 与数学「电表」打通 |
| **春联/节日** | 门上贴的福/春/全家和睦 | 每天路过家门就在复习 |

**注意打通价值**：读一读不是孤立模块，它把识字、数学、科普三个模块的场景**合流到真实材料**上。这是内容延伸里杠杆最大的一块。

### B2. 数字生活科普主题 ★★（评审清单里已有，这里展开）

给科普的「机动 12 条」让位或加 6–8 条：
- 微信怎么接视频电话（分步骤、配真界面描述）
- 怎么把字体调大（正好和 App 自己的设置页互为练习场）
- 相册怎么看孙子的照片
- 二维码：什么能扫、什么不能扫（防诈骗联动）
- 手机音量/亮度调节

### B3. 节令认字（春联优先）★★

春节是天然的大字环境——门上的春联每天路过都在复习。立春/中秋/生日的贺词可以做「应景字包」，成本低（10–20 字），情感联结强。

### B4. 3500 字第二阶段 ★☆（远期预留，不是现在）

框架已天然支持：字表源就是 3500 一级字表，排程算法、SRS、管线全是现成的，改一个数字即可。**但先别做**——1800 没巩固完之前谈 3500 是 scope creep。放在「学完 1500 字后」由家属端解锁。

### B5. 「字的故事」轻量版 ★☆（看兴趣）

前 30 天的字里有大量象形/会意字（日月水火山口手目）。配一句「山：三个峰，古字就是画的三座山头」——字形溯源对记忆有实证帮助。放在「读一读」卡片的可选尾注，不做独立模块。若奶奶对这个有兴趣再扩。

### 不延伸的（和评审一保持一致）

拼音输入（语音替代）· 全量写字 · 英语 · 戏词字幕（诱人但工作量与主线不成比例）· 历史/戏曲兴趣课。

## 优先级合并视图（含前 6 缺口 + 本次 A/B）

**第一梯队（一次迭代做完）**
1. 读一读模块（B1 场景库）+ 留言大字阅读（缺口2）
2. 家属端弱点清单（缺口3）→ 顺带 A3 字卡导出（同一数据）
3. 专属字包 A1（家人名字进字序最前）+ A7 描红（写名字）
4. A6 设置页（字号/语速/提醒）+ A4 每日通知
5. 磨耳朵 A5（恢复听一听）

**第二梯队（看真机反馈再定）**
6. A2 家人真声教字（需要你愿意录）
7. 数学摸底（缺口4）+ SRS 第5档（缺口5）+ 场景词组（缺口6 前三条合并）
8. B2 数字生活科普 + B3 节令字包

**前置条件（不变）**：确认普通话听力 → 真机首测视力（决定 A6 默认档位）。
