# 内容框架评审

> 评审对象：当前 App 的学习内容框架（识字 / 生活数学 / 科普 三模块 + 复习机制 + 双端）
> 评审目标：这是给奶奶（老年人、基本不识字）用的，判断「规划对不对、还缺什么」。
> 日期：2026-11-12

---

## 一、总体结论

**框架骨架是对的，而且不是我们拍脑袋想的。**

教育部《扫盲教育课程设置及教学材料编写指导纲要》（教基一〔2011〕1号）给成人脱盲定了三科结构：

| 纲要三科 | 我们的模块 |
| --- | --- |
| 生活中的读与写 | 识字（1800 字 + 组词） |
| 数与算 | 生活数学（90 节） |
| 知与能 | 科普（90 条） |

**一一对上。** 字表来源（592 最高频 / 358 次高频 / 550 非高频的分层）也出自同一纲要——这正是「一个不认字的成年人最先需要认识哪些字」的官方答案。音频先行（老人可能老花）、离线优先（不依赖网络）、每日任务不锁时段——这些方向都对。

**但按「奶奶真正用得上」这个标准去查，有 6 个真实缺口。** 框架没错，是「够不够」的问题。

---

## 二、六个真实缺口（按价值排序）

### 缺口 1：只教到「词」，没教到「读」★★★（最大的缺口）

现在识字流程是：单字 → 词组 → 二选一认读。到「词」就停了。

但奶奶的最终目标是**读懂一段真实文字**：药盒上写什么、微信里孩子说了什么、通知贴了什么。从「认得字」到「读得懂」中间还差一级台阶，现在整个框架没有这一级。

**建议：加第四模块「读一读」**——从第 16 天起（约 200 字存量后），每天 1 张短文阅读卡：
- 长度 1–2 句起步，全部由**已学过的字**组成（不引入生字，保证能读通）
- 内容就是真实场景：药盒「一日三次，一次一片」、公交「2 路开往火车站」、价签「鸡蛋 六元一斤」、医院「内科在三楼」
- 可逐句点读、全文朗读
- 约 60–75 张，随字量增长变长

这同时补上「科普卡正文她只能听不能读」的问题——科普卡维持听力材料，「读一读」才是她的阅读材料。

### 缺口 2：家人留言做了一半，而这恰好是最强动机的真实文本 ★★★

代码里首页有「家人留了话」入口，但点开是空的（注释写着「下一版用预生成语音播报」）。

**建议：把留言直接变成大字阅读卡。** 你发的一句话，在奶奶端用楷体大字 + 喇叭展示、可反复点读。这一句话她会认真看十遍——因为是她孙子/孙女写的。没有任何教学内容能比这个更 motivating，而且功能已经建了一半。

### 缺口 3：数学没有摸底测试 ★★（防弃用问题）

数学从第 1 课「认识 1 到 5」开始，所有人都从头学。

奶奶大概率会买菜、认识钱。第一课教她数手指，她可能觉得「这是哄小孩的」——**对老人来说，被当成小孩教是弃用的第一原因**，比难更危险。

**建议：首次进入数学前 5 题摸底**（认识数字吗 / 会算 6+3 吗 / 认识人民币面额吗 / 会看整点时间吗），跳到对应起点。会数钱的奶奶直接从「人民币」模块开始。

### 缺口 4：复习深度对老人不够 ★★

现在 4 次复习（D+1/D+3/D+8/D+21）跨两个时段答对 2 次就判「掌握」。

研究结论（PMC4480221 等）：间隔复习对老人**有效但衰减**，比年轻人需要更多次重复。4 次对老人偏少。

**建议：** 掌握门槛从「跨时段连对 2 次」提到 3 次；复习档位加第 5 档（60 天）——即一个字要跨约 3 个月、5 次正确才算真正巩固。巩固日（每 7 天）保留。

### 缺口 5：词组按语料词频选，不是按生活场景选 ★★

词组来自 jieba 词频，抽查实际结果：

- 人 → 人民、人们、人口
- 日 → **日本**、日子、日常
- 水 → **水平**、水产、水中

「日本」「水平」对奶奶价值很低。她的高频世界是：药盒、医院、公交、超市、银行、家人的名字。

**建议：改为场景词表优先**——为每字挑词时优先从「医院/超市/公交/银行/家用药」场景词库里挑（词库本身仍可用 jieba 校验是真词），词频只做兜底排序。

### 缺口 6：家属端答不出「她哪些方面弱」★★★（正好回答你这次的问题）

你说想知道「她还有哪些方面可以学习」。现在的家属端只有汇总正确率和进度——看不出她卡在哪。

**事件日志里逐字对错数据已经有了**（老人端每次作答都上传 char + result），只是没有聚合展示。

**建议：家属端加「弱点清单」**——常错字 TOP20（按答错次数排）、分主题正确率（数学按模块、科普按主题）、最近 3 天新学的字。这一条直接把你的问题变成产品功能：打开家属端就看到「这 20 个字她老记不住，你可以当面陪她认一认」。

## 三、两个没人验证过的前提（比任何功能都优先）

在加任何模块之前，这两件事需要你（或家人）跟奶奶本人确认：

### 前提 1：她听普通话舒服吗？

App 全部音频是标准普通话（微软 zh-CN 音色）。如果奶奶是**强方言使用者**（比如只说某方言、普通话听着吃力），这是第一个 blocker——「听」是她唯一的入口。

- 若她普通话没问题 → 不用动
- 若吃力 → 需要降级预期、更慢语速（现在 0.9 速），甚至考虑换方言 TTS（那要重排音频管线，工作量大）

### 前提 2：视力/色觉实际情况

对比度全部按 ≥7:1 做了（对白内障的黄色化晶状体友好，避开了蓝通道低对比）。但「设计规范达标」和「她本人看着舒服」不是一回事——第一次真机使用时看她会不会凑得很近、会不会眯眼。

## 四、不建议加的（同样重要）

| 不加 | 理由 |
| --- | --- |
| 拼音输入 / 打字 | 语音输入已存在；老人手部精细动作困难，学输入法投入产出比极低 |
| 系统性写字 | 20 字/天的前提就是「只认读」。写字一笔一划，量提不上来。可选加「写自己名字 + 数字」最小集，仅此而已 |
| 历史故事 / 戏曲等「兴趣课」 | 三科结构已覆盖功能性识字；加学科是 scope creep，老人的精力有限，宁可做深 |
| 英语 | 无使用场景 |
| 更难的数学（乘除以外） | 数学模块止于「过日子算清账」，纲要对成人脱盲的数与算就是这个边界 |

**框架里缺的不是新的「学」，缺的是「用」。** 识字到用字的那一步（读一读 + 留言阅读）比任何新课程都值钱。

## 五、节奏的诚实评估（需要你拍板）

1800 字 ÷ 90 天 = **每天 20 个新字**，是研究建议量（3–5 个/天）的 4–6 倍。

自适应降速已有（连续 7 天正确率 <70% → 自动减半 + 顺延），但它是「失败后补救」。两个选项：

| | A：保持 20/天 | B：默认 10/天 |
| --- | --- | --- |
| 周期 | 90 天（顺延机制兜底） | 约 180 天（半年） |
| 依据 | 你此前的明确要求 | 更接近老人研究节奏 |
| 风险 | 遗忘率高、靠降速机制兜 | 起步就稳，家属端可上调到 15/20 |

**我的建议是 B**，家属端可随时调上去——但这改的是你拍过的板，你来定。

## 七、奶奶除了识字，还能学什么（回答「还有哪些方面」）

按模块归位，不另开新课：

- **用手机**（最有现实价值的延伸）：微信收发语音/视频通话、调大字体——科普加「数字生活」主题正好装这个；App 本身就是她的手机练习场
- **防诈骗实操**：现有 14 条是知识判断题，可在「读一读」里加实操版（让她读一条仿真短信、判断真假）
- **健康管理**：数学已有读血压/体温；家属端可加「最近正确率曲线」让家人发现状态变化
- **出行**：公交/地铁阅读材料放进「读一读」场景库

这些都装得进现有三科 + 新的读一读模块，框架不用推翻。
